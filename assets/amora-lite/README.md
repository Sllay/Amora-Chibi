# Amora Lite — produção 2D

Arte-mestre e futura extração modular da Amora Lite.

- `reference/`: imagem original imutável e notas de origem.
- `masks/`: máscaras anatômicas produzidas pelo pipeline.
- `sprites/`: camadas RGBA derivadas, sujeitas à revisão visual.
- `previews/`: composições de prova, comparações e testes de movimento.

Regra: a imagem de referência é a única fonte artística aprovada. Não declarar que camadas ou sprites estão prontos antes de sua validação.
