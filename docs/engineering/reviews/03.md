## Correção após primeiro Turso real — 2026-10-25

Evidência operacional relatada por BK no deploy Northflank → Turso: HTTP 200
em `/v2/pipeline`, migrations executadas, mas COMMIT retornava `baton=null` e
o Core encerrava com erro. URL/auth estavam funcionando. O adapter verificava
continuidade do stream antes de processar o resultado SQL, classificando um
fechamento legítimo como STREAM_LOST/OUTCOME_UNKNOWN. Este bug só apareceu no
primeiro Turso real porque o mock anterior sempre mantinha baton até `close`.

Correção limitada a `core/amora/storage/remote.py`: processar o resultado de
execute antes de validar a continuidade. Apenas COMMIT/ROLLBACK explícitos,
com resposta `ok/execute` e resultado processado normalmente, permitem baton
nulo sem close adicional. Close explícito continua permitido. BEGIN e demais
statements sem baton continuam falhando e invalidando a conexão. Erro SQL do
terminador não vira sucesso; falha HTTP/transport continua
`SQL_TRANSPORT_FAILED_OUTCOME_UNKNOWN`. Não há retry de COMMIT/write ambíguo.

`HranaSQLite` agora encerra o stream ao final de pipelines com terminador
bem-sucedido, se não restar transação aberta, sem depender de close. Um modo
opcional preserva o comportamento anterior para testar ambos os servidores.
As migrations existentes passam nesse novo comportamento; segunda conexão
confirma schema 11, dedupe e estado persistidos. Não se alterou schema,
migration, seleção de storage, domínio, segurança, tokens, providers ou voz.

Validação local:

- `.venv/bin/python -m pytest -o addopts= tests -q`:

Regressões incluem COMMIT com baton nulo ou retido, erro de statement seguido
de ROLLBACK com baton nulo, baton perdido em BEGIN/leitura/escrita, HTTP 503 e
timeout após COMMIT aplicado (uma única tentativa), StreamResult error em
COMMIT/ROLLBACK, resposta malformada de terminador, migration completa e restart.

Não há decisão de produto/arquitetura nova para BK. Risco restante: esta correção
foi validada localmente contra o mock corrigido; repetir startup/migrations e
restart no staging real é o próximo gate. O agente não executou novo deploy nem
afirma certificação adicional de Northflank/Turso.
