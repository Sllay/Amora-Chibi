# AMORA — Canon

Este diretório contém a **verdade atual** da Amora.

Leia:

1. [`SKILL.md`](SKILL.md) — regras para trabalhar no projeto;
2. [`ARCHITECTURE.md`](ARCHITECTURE.md) — como o sistema funciona;
3. [`GDD.md`](GDD.md) — o que a Amora deve ser e como deve se comportar.

Documentos históricos, checkpoints de versão e commits antigos não substituem estes arquivos quando houver divergência.

Para entender **por que** algo mudou, consulte `../decisions/`.

Para entender **para qual versão** uma feature foi movida, consulte `../roadmap/VERSIONS.md`.

Nunca restaurar solução antiga apenas porque ela aparece em documentação histórica. Primeiro verifique se existe ADR `REJECTED`, `SUPERSEDED` ou decisão posterior.
