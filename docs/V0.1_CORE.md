# V0.1 — Core Foundations

Esta versão implementa a fundação necessária antes de voz, memória semântica e emoção.

## Garantias atuais

- `PERSON_BK` persiste e resolve `BK`, `Bad King`, `Slay` e `Nick`.
- palavras relacionais (`pai`, `mãe`, `filha`) não são aliases globais.
- eventos com a mesma identidade/dedupe key não são aplicados novamente após restart.
- pessoa, dispositivo e sessão são registros distintos.
- secrets ficam fora do banco cognitivo e do Git.
- migrations são versionadas.
- banco pode ser verificado, backupeado e restaurado.
- API é localhost-only e exige bearer token para endpoints `/v1/*`.

## Limites intencionais

A V0.1 **não** implementa:

- VAD/STT;
- Speaker/Addressee Engine;
- Perspective Resolver / ACIR;
- memória episódica/semântica;
- emoções;
- drives/autonomia;
- providers reais;
- avatar.

Esses módulos pertencem aos estágios seguintes do roadmap canônico.
